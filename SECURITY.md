## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, or pull request.

Use [GitHub private vulnerability reporting](https://github.com/ioplane/terraform-provider-nutanix/security/advisories/new). If that form is unavailable, open the repository's **Security** tab and follow the private **Report a vulnerability** flow.

Include the affected revision or version, impact, reproduction steps, and any suggested mitigation. Remove credentials, Nutanix endpoints, Terraform state, and other sensitive environment data from the report and attachments.
